# Скриншоты для гайда по DeepSeek Harness

Картинки из статьи «DeepSeek Harness: как поставить за 5 минут и подключить
модель bunny». Лежат здесь потому, что Telegraph не умеет принимать файлы
на загрузку — его редактор просит готовый URL, а штатный эндпоинт `telegra.ph/file`
отдаёт 404. Статья подставляет эти ссылки напрямую.

| Файл | Что на нём |
| --- | --- |
| `shots/test-boot.png` | первый запуск `dsh web`, окно Preview Notice |
| `shots/test-main.png` | главный экран агента с выбором рабочей папки |
| `shots/test-models.png` | Settings → Models, список провайдеров |
| `shots/test-add-provider.png` | окно добавления провайдера из каталога |
| `shots/test-openrouter-edit.png` | OpenRouter и поле API key |
| `shots/test-bunny-provider.png` | провайдер Bunny (OpenRouter) появился после настройки |

Статья: https://telegra.ph/DeepSeek-Harness-kak-postavit-za-5-minut-i-podklyuchit-model-bunny-10-01

Снимки сделаны на чистой установке DeepSeek Harness 0.2.0-rc.2 в отдельном
`DSH_HOME`, поэтому на них нет личных ключей и содержимого рабочих папок.
